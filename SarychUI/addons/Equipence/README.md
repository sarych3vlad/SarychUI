## 🔥 Features

- 💎 **Gems** and **sockets** (including empty and **prismatic** sockets).
- ✨ Optional **shine** for matching gems.
- 🪄 **Enchants**, **missing enchant** marks, and helpful tooltips.
- 🔢 **Item level** per slot and average item level.
- 🎨 **Quality borders** and item level coloring.
- 👥 Works for your **character** and **inspected** characters.
- 🧭 Live **options panel** for quick visual tuning.

## 📂 Install

1. [Download](https://github.com/s0h2x/Equipence/releases/latest/download/Equipence.zip) the latest release, or use the button above.
2. Extract the package into the matching `Interface/AddOns` folder for your WoW client.
3. Restart the game.
4. Enable `Equipence` in the AddOns list.

> The final folder must be named exactly `Equipence`. <br />
> Do not use names like `Equipence-1.0`, `Equipence-main`, or `Equipence-master`.

## ⚙️ Options

Options are available from the game menu: `Menu → Interface → AddOns → Equipence`

Available slash commands:

```text
/eqc
/equipence
```
